# Character frame guide

`serenial-character-96x96-guide.png` is an authoring overlay, not a runtime frame.

- cyan rectangle: safe visible bounds;
- blue vertical line: horizontal anchor center at x 48;
- amber horizontal line: ground anchor at y 84;
- magenta cross: exact anchor point (48, 84).

Import the guide as a locked layer in a pixel editor. Draw on separate layers, then hide the guide before exporting a 96 x 96 RGBA PNG.
