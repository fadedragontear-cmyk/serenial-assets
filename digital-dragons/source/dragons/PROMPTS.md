# Digital Dragon source prompts and design locks

The original reference sheets were generated within the Fade Dragontear Celdraverse project.
When recreating or extending a species, preserve its silhouette, scale pattern, horn placement, wing shape, eye color, elemental effect language, and right-facing race direction.

## Runtime dragon prompt template

Create a high-detail game asset for **{asset_key}**, a {element} Digital Dragon. Match the supplied reference exactly: same anatomy, horns, face, wing structure, scale markings, palette, and elemental effects. Full-body pose facing right, centered, clear silhouette, no text, no frame, clean transparent background, soft semi-transparent elemental particles, production-ready 2D fantasy game art.

## 32×32 sprite prompt template

Create crisp hand-pixelled 32×32 frames for **{asset_key}**, preserving the supplied dragon design. Transparent background, no antialiasing, consistent feet/body-base anchor, four direction rows ordered Down, Left, Right, Up. Keep anatomy and markings stable across idle, walk, attack, cast, hurt, victory, and defeat.
